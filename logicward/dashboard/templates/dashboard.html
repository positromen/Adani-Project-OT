This site is monitored on the register plane (live Modbus holding registers & coils diffed against the signed baseline). The OpenPLC controller runs Structured Text, not Rockwell L5X, so the rung-level program diff shown for the thermal plant does not apply here. A Structured-Text program-drift parser is on the roadmap — for now, setpoint and command tampering are caught as register drift and appear in the unified alert feed.

Roles & Access Definitions
OT/ICS functional roles and their monitored scopes within LogicWard.
🧑‍🏭
Operator (DCS/Control Room)
Live Plant Access
  • Live HMI/plant view and real-time alarm feed access only.
  • Normal behavior involves acknowledging alarms during shift hours.
  • Monitored for setpoint changes outside pre-approved operating limits.
Live HMI Alarm Ack
🧑‍🔧
C&I / Control Engineer
PLC Program Access
  • Baseline capture, program (L5X) diff view, re-baseline and restore actions.
  • Normal behavior involves scheduled maintenance-window logic pushes.
  • Monitored for unscheduled ladder logic or setpoint edits.
PLC Logic Baseline
🧑‍💻
OT Network / Security Engineer
Infrastructure Access
  • Firewall, DMZ, and network segmentation configuration access.
  • Normal behavior includes patch scheduling and asset inventory updates.
  • Monitored for unapproved port changes or lateral-movement patterns.
Network Configs Firewall
🕵️
SOC Analyst
Oversight Role
  • Full alert feed access, MITRE ATT&CK mapping, forensic PDF export.
  • Normal behavior includes alert triage and incident investigation.
  • Monitored for tampering with alert states or self-closing incidents.
Security Dashboard Evidence Export
👷
Vendor / OEM Contractor
Scoped External Access
  • Time-bound, highly restricted access to specific PLC/RTU for maintenance.
  • Normal behavior is strictly contained to assigned IPs and time windows.
  • Monitored heavily for any deviation or escalation attempts.
VPN Access Scoped Dev
🧑‍💼
CISO / Plant Cybersecurity Head
Incident Command & Compliance
  • Full cross-role visibility, final incident sign-off, compliance reporting.
  • Normal behavior includes periodic audit review and CERT-In reporting.
  • Monitored for out-of-cycle role/permission changes.
Full Access Compliance
